# 交付岗位面试录用规则
## 核心说明
1. **适用范围**：交付岗位全级别面试录用评估，覆盖6个级别：A1-A3、A4-A6、P1-P3、P4-P6、A7-A9、M1-M3
2. **评估体系**：包含4大类维度，其中单元三板斧为特殊维度（仅针对单元负责人）
3. **单元三板斧适用范围**：仅带团队的单元负责人（A7-A9级别、M1-M3级别），其他级别不纳入评估
4. **评分规则**：采用百分制，按维度权重计算加权总分；录用结论分A+（优秀）、A（良好）、B（合格）、C（淘汰）四档

## 八、模型训练专用说明
### 8.1 关键特征提取指引
- **级别标签**：A1-A3、A4-A6、P1-P3、P4-P6、A7-A9、M1-M3（6个分类标签）
- **维度标签**：AI能力、兴趣、智商、狼性、情商、快、画施工图、选好骨干、提高人效（9个维度标签）
- **权重特征**：各维度权重占比（如智商25%、狼性15%）
- **合格线特征**：各维度合格线数值（如AI能力≥80、选好骨干≥90）
- **结论特征**：A+、A、B、C（4个结论标签）

### 8.2 数据关系逻辑
1. 级别→维度：不同级别对应不同的评估维度组合（单元负责人多3个维度）
2. 维度→权重：每个维度在对应级别下有固定权重
3. 维度→合格线：每个维度在对应级别下有固定合格线（部分维度无）
4. （维度得分×权重）→ 总分：加权总分计算逻辑
5. （维度合格线达标+总分达标）→ 结论：录用结论判定逻辑
