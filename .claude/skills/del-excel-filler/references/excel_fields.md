### 轮次定义
- **初试**：第1轮面试
- **线下协同初试**：线下协同的第1轮面试
- **复试**：第2轮面试
- **终试**：第3轮面试（终面/三面）

## 面试轮次自动识别规则

大模型自动从面试文本/用户指令判断面试轮次：

| 关键词 | 判定轮次 |
|--------|----------|
| 第一次/初试/一面/初面 | 初试 |
| 线下协同/协同初试/线下面试 | 线下协同初试 |
| 第二次/复试/二面/二轮 | 复试 |
| 第三次/终试/三面/终面/三轮/最终 | 终试 |
| 无明确关键词 | 初试（默认） |
