description: 交付岗位面试Excel本地填表工具。当用户上传简历或面试文本，并要求填写到本地Excel表格时触发此skill。此skill会调用del-CR分析简历、调用del-IID分析面试，然后将分析结果填入本地Excel模板副本中。适用于招聘场景中候选人信息归档、面试评价记录。
---

## 核心能力
此skill完成以下工作流：
1. 调用del-CR分析简历，提取基本信息+亮点疑点风险
2. 调用del-IID分析面试文本，获取面试评分、依据、录用建议
3. **自动识别面试轮次：初试/复试/终试**
4. 复制本地Excel模板到候选人存储文件夹
5. 使用Python+openpyxl将分析结果写入Excel对应轮次区域
6. 返回填写好的Excel文件路径

## 触发条件
满足以下任一场景时触发：
- 用户上传简历文件（PDF、Word、文本），并要求"填入Excel"、"生成评价表"
- 用户上传面试文本，并要求"填写面试评分"、"生成评价表"
- 用户说"创建面试评价表"、"生成这个候选人的评价表"

## Excel字段位置
所有字段的填写位置、轮次列映射、JSON数据格式详见：
- [references/excel_fields.md](references/excel_fields.md)

## 面试轮次自动识别规则
大模型自动从面试文本/用户指令判断：
- 包含**第一次/初试/一面** → 判定为 **初试**
- 包含**第二次/复试/二面** → 判定为 **复试**
- 包含**第三次/终试/三面/终面** → 判定为 **终试**
- 无明确轮次 → 默认 **初试**

## 工作流程
### 步骤1：调用下游skill分析
根据用户输入判断：
**场景A：用户只上传简历**
1. 调用del-CR分析简历，获取基本信息+简历识别结果
2. 将del-cr输出保存为JSON

**场景B：用户只上传面试文本**
1. 调用del-IID分析面试，获取面试评分、依据、录用建议
2. **大模型自动识别面试轮次（初试/复试/终试）**
3. 将del-IID输出保存为JSON

**场景C：用户同时上传简历+面试**
1. 先调用del-cr分析简历
2. 再调用del-IID分析面试（需要简历信息作为输入）
3. **大模型自动识别面试轮次（初试/复试/终试）**
4. 合并两个skill的输出

### 步骤2：复制Excel模板
从skill资源目录复制模板到候选人存储文件夹。
- **模板源文件**: `template.xlsx`
- **目标文件夹**: 候选人姓名_手机号_日期
- **目标文件名**: `{候选人姓名}_{日期}_面试评价表.xlsx`

### 步骤3：填写Excel
使用 [`scripts/fill_excel.py`](scripts/fill_excel.py) 脚本填入数据。

JSON输入格式（字段名严格对齐 references/excel_fields.md）：
```json
{
  "resume_data": {
    "姓名": "张三",
    "电话": "13800138000",
    ...
  },
  "interview_data": {
    "round_type": "初试/复试/终试",
    "AI能力": 80,
    "底色-兴趣": 85,
    ...
    "评分依据": {
      "AI能力": "熟悉AI工具..."
    },
    "级别建议": "P6",
    "薪资建议": "25K",
    "说服建议": "强烈推荐",
    "其他建议": ""
  }
}
```

调用方式：
```bash
python scripts/fill_excel.py data.json [轮次]
```
例如：
```bash
python scripts/fill_excel.py data.json 初试
```

### 步骤4：返回结果
返回填写好的Excel文件路径告知用户。
