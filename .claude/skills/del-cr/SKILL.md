# delCR — 交付岗位简历筛选与分析

## 核心原则(加速执行)

1. **单次扫描完成所有判定** - 读取简历时同步完成黑白灰判定和评分
2. **查references获取规则** - 黑白灰规则见 `references/delBlackWhite.md`，评分标准见 `references/delScoringRubric.md`
3. **基准线给分** - 简历无信息时按基准线给分,不再给0分
4. **快速通道** - 先执行黑白灰判定,如有黑清单直接输出淘汰结论
5. **级别自动识别** - 根据工作年限自动识别A1-A3/A4-A6/P1-P3/P4-P6/A7-A9/M1-M3

## 评分铁律

1. **只允许根据简历中明确出现、可被直接验证的信息进行打分**
2. **简历无信息=基准线给分**：按 [references/delScoringRubric.md](references/delScoringRubric.md) 的基准线给分
3. **打分必须100%基于简历原文**
4. **智商小计**=数学成绩×45%+毕业院校×35%+简化能力×20%
5. **"快"维度小计**=态度×20%+硬能力×50%+软能力×30%
6. **三板斧1~5级映射**:1级=60,2级=65,3级=75,4级=85,5级=95
7. **加权总分**=Σ(维度得分×权重)

## 黑白灰快速判定

### 关键判定规则

详细黑白灰规则见 [references/delBlackWhite.md](references/delBlackWhite.md)

**快速检查项（X1/X2级别）**:
- 第一学历：985/211 → 白；双一流/公立本科对口 → 灰；民办/非全日制/大专 → 黑
- 年龄：≤25岁 → 白；26岁 → 灰；≥27岁 → 黑
- 工作时间：≤3年 → 白；4年 → 灰；>4年 → 黑
- 岗位：DBA/数据库工程师 → 白；数据分析/数仓/IT运维 → 黑

### 基准线要求

| 基准项 | 最低要求 |
|--------|----------|
| AI能力 | ≥80 |
| 兴趣 | ≥80 |
| 狼性 | ≥80 |
| 智商 | ≥80 |
| 情商 | ≥70 |
| 快-硬能力 | ≥60 |
| 快-软能力 | ≥60 |
| 快-态度 | ≥60 |

## 快速执行流程

1. **扫描简历** → 提取基础信息（学历、年龄、工作年限、岗位、技术）
2. **识别级别** → 根据工作年限确定X1/X2/X3+/A7-A9/M1-M3
3. **黑白灰判定** → 快速检查关键项，命中黑清单直接输出淘汰
4. **评分** → 按 references/delScoringRubric.md 进行各维度评分
5. **计算总分** → 按级别权重计算加权总分
6. **输出结论** → 格式：[评分 | 评级 | 黑白灰] [岗位级别]
