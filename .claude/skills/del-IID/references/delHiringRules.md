# 交付岗位面试录用规则

> 本文件用于指导AI进行交付岗位面试的录用判定

---

## 一、黑白灰优先级

1. **黑清单 > 灰清单 > 白清单**
2. 面试任一维度命中黑清单 → 直接淘汰（C），无需继续评分
3. 命中灰清单的维度需结合整体评估，不可直接淘汰

---

## 二、各级别录用判定

### A1-A3级别（普通交付岗位）

| 判定条件 | 录用结论 |
|----------|----------|
| 所有维度达到合格线，且智商≥90、AI能力≥90 | **A+（优秀）** |
| 所有维度达到合格线，且智商≥85、AI能力≥85 | **A（良好）** |
| 所有维度达到合格线（无额外分数要求） | **B（合格）** |
| 任意一个维度未达到合格线 | **C（淘汰）** |

**合格线**：AI能力≥80，兴趣≥80，智商≥80，狼性≥80，情商≥70，硬能力≥60，软能力≥60，态度≥60

## 三、级别识别

根据工作年限自动识别级别：

| 工作年限 | 对应级别 |
|---------|----------|
| ≤3年 | X1(A1-A3) |
| 4年 | X2(A4-A6) |
| >4年非带团队 | X3+(P1-P6) |
| 带团队(≤3人) | A7-A9 |
| 带团队(>3人) | M1-M3 |

## 四、加权总分计算

### 普通岗位（A1-P6）

| 考核项 | 权重 |
|-------|------|
| 底色-狼性 | 22.5% |
| 底色-智商 | 27.5% |
| 岗位三板斧-快 | 25% |
| 岗位三板斧-收款 | 10% |
| 岗位三板斧-扩项 | 15% |

**加权总分** = 狼性×22.5% + 智商×27.5% + 快×25% + 收款×10% + 扩项×15%
