# 交付岗位面试评分标准

> 本文件用于指导AI进行交付岗位面试评分

---

## 一、底色评分标准

### AI能力（及格线≥80）

| 分值 | 标准 |
|------|------|
| 90-100 | 主动拥抱AI，精通各类AI工具，显著提升故障处理效率、人效远超团队平均，持续学习并带动团队 |
| 80-89 | 认可AI价值，熟练使用主流AI工具，主动关注AI新应用并乐于分享 |
| 60-79 | 被动使用AI，掌握基础功能，效率提升不明显，主动性弱 |
| 40-59 | 尝试使用但不得法，效果差，学习意愿低，未带来实际效益 |
| <40 | 拒绝AI，固守旧法，效率低下，抵制学习，躺平摆烂 |

### 兴趣（及格线≥80）

| 分值 | 标准 |
|------|------|
| 90-100 | 热爱服务与交付，以客户成功为成就，主动解决问题、扛事、优化 |
| 80-89 | 认可服务价值，责任心强，主动跟进，耐心抗压 |
| 60-79 | 不排斥服务，能按流程完成，耐心尚可 |
| 40-59 | 兴趣一般，被动响应，易烦躁 |
| <40 | 讨厌服务、怕客户、怕麻烦，推诿敷衍 |

### 情商（及格线≥70）

| 分值 | 标准 |
|------|------|
| 90-100 | 极度耐心稳定，先安抚再解决，扛压扛委屈，能化解冲突、建立信任 |
| 80-89 | 情绪稳定，会安抚客户，冲突理性处理 |
| 70-79 | 基本耐心，职业规范内沟通正常 |
| 40-59 | 耐心不足，易烦躁，态度易受影响 |
| <40 | 情绪易爆，怼客户、甩脸色，破坏口碑 |

### 狼性（及格线≥80）

| 分值 | 标准 |
|------|------|
| 90-100 | 问题不解决不离场，紧急故障主动扛，再苦再累也要交付成功 |
| 80-89 | 以客户成功为底线，敢担责、不甩锅，问题闭环到底 |
| 60-79 | 能按要求完成交付，有基本责任心 |
| 40-59 | 怕麻烦怕加班，被动应付，主动性弱 |
| <40 | 怕担责、敷衍推诿、情绪优先 |

**狼性补充评估（30分制）：**
- **目标必达**：30分=零借口死磕到底；27分=重压下必完成；24分=稳定达标；21分=勉强达标；<21分=不达标
- **凡事闭环**：30分=事事有最终结果；27分=主动反馈有头有尾；24分=能闭环不甩锅；21分=被动闭环易甩锅；<21分=常甩锅不闭环

## 二、智商评分标准（面试补充）

| 分值 | 标准 |
|------|------|

**智商小计** = 数学成绩×45% + 毕业院校×35% + 简化能力×20%

## 四、单元三板斧评分标准（仅A7-M3）

### 画施工图（无固定及格线）

| 分值 | 标准 |
|------|------|
| 90-100 | 精准拆解战略目标，路径清晰，风险预见性高，执行无偏差 |
| 80-89 | 目标拆解合理，关键节点明确，有预案，执行基本顺畅 |
| 70-79 | 计划基本可行但细节不够完善，风险识别不全，需多次调整 |
| 60-69 | 计划粗糙，路径模糊，风险频发，执行混乱 |
| <60 | 无计划或计划完全不可行，项目推进失控 |

### 选好骨干

| 分值 | 标准 |
|------|------|
| 90-100 | 慧眼识人，精准识别高潜，骨干梯队健康不断涌现 |
| 80-89 | 能识别优秀人才，骨干队伍稳定，偶有偏差能及时调整 |
| 70-79 | 识人眼光一般，任用存在错配，但骨干基本稳定 |
| 60-69 | 识人眼光差，骨干流失严重或长期空缺 |
| <60 | 嫉贤妒能，压制人才，团队无骨干，团队溃散 |

**A7-A9及格线**：≥80
**M1-M3及格线**：≥90

### 提高人效（无固定及格线）

| 分值 | 标准 |
|------|------|
| 90-100 | 人效显著高于同规模团队，人才培养体系完善 |
| 80-89 | 能完成业务目标，推动流程优化，有带出骨干 |
| 70-79 | 勉强完成目标，流程工具基本到位但不系统 |
| 60-69 | 经常加班产出不佳，士气低落，新人成长慢 |
| <60 | 产出无法支撑业务，士气崩坏，成为业务瓶颈 |

## 五、评分铁律

1. **所有评分必须有明确依据**——面试文本原话，拒绝无依据打分
2. **面试文本中未涉及的维度**，按基准线给分并标注"建议后续核实"
3. **基准线**：AI能力/兴趣/狼性/智商取80分，情商取70分
4. **三板斧1~5级映射**：1级=60, 2级=65, 3级=75, 4级=85, 5级=95
