# 交付岗位面试黑白灰清单

> 本文件用于指导AI进行交付岗位面试评估的黑白灰判定

---

## 一、面试基础信息黑白灰

### 形象管理

| 判定 | 标准 |
|------|------|
| 黑 | 不修边幅，毫无面试准备；奇装异服、行为夸张 |
| 白 | 着装和举止得体、准备充分 |

### 时间观念

| 判定 | 标准 |
|------|------|
| 灰 | 面试卡点；面试迟到 |
| 白 | 提前到达，互通有无 |

### 工作业绩

| 判定 | 标准 |
|------|------|
| 灰 | 过往在职期间绩效考核C；工作岗位或业务条线边缘化 |
| 白 | 过往在职期间绩效考核B及以上；不断升职 |

### 离职原因

| 判定 | 标准 |
|------|------|
| 黑 | 对原公司、原上级评价超级负面；因绩效不达标被公司优化 |
| 灰 | 家人生病需要照顾；家里装修；公司政策性裁员；裸辞 |
| 白 | 正常职业发展原因 |

### 求职期望（职业规划）

| 判定 | 标准 |
|------|------|
| 黑 | 职业发展无规划，岗位深耕不足、赛道频繁切换；始终处于行业底层或岗位边缘 |
| 灰 | 有规划但模糊 |
| 白 | 有清晰的职业发展方向，能在目标赛道岗位稳步沉淀能力 |

### 当前薪资

| 判定 | 标准 |
|------|------|
| 灰 | 将补助算进底薪部分 |
| 白 | 薪资结构清晰、可提供依据 |

### 期望薪资

| 判定 | 标准 |
|------|------|
| 灰 | 期望薪资和个人能力偏差小或偏差较大但可说服 |
| 白 | 期望薪资合理 |

### 期望城市

| 判定 | 标准 |
|------|------|
| 灰 | 期望城市和岗位城市不一致，但近3年可接受在岗位城市发展 |
| 白 | 期望城市和岗位城市一致 |

---

## 二、底色黑白灰

### AI应用能力

| 判定 | 标准 |
|------|------|
| 黑 | 抵触使用AI，固守旧法，效率低下，抵制学习 |
| 灰 | 掌握AI基础功能，能完成简单任务，需提升效率 |
| 白 | 认可AI，熟练使用核心工具辅助业务，效率提升明显 |

### 兴趣

| 判定 | 标准 |
|------|------|
| 黑 | 无兴趣无动力，完全依赖外部推力，缺乏自驱力与使命感，难以胜任 |
| 白 | 极强内驱力，热爱本职，抗压性爆棚，无需监督全力以赴 |

### 狼性

| 判定 | 标准 |
|------|------|
| 黑 | 被动等靠要，频繁完不成目标找理由，烂尾推诿 |
| 白 | 无指令也能主动破局，目标必达死磕到底，凡事有最终结果 |

### 情商

| 判定 | 标准 |
|------|------|
| 黑 | 耐心不足、情绪易爆 |
| 白 | 耐心稳定，能化解冲突、建立信任 |

## 三、岗位三板斧黑白灰

### 快-硬能力

| 判定 | 标准 |
|------|------|
| 白 | X1-硬能力1级；X2-硬能力2级；X3+-硬能力3级+ |

### 快-软能力

| 判定 | 标准 |
|------|------|
| 白 | 具备AI应用能力；遵守流程规范、操作细则、公司红黄线；按时闭环工作任务、完成工作文档撰写、配合团队协作 |

### 快-态度

| 判定 | 标准 |
|------|------|
| 白 | 积极主动 |

### 收款

| 判定 | 标准 |
|------|------|
| 白 | 有收款意识，有成功催款经历 |

### 扩项

| 判定 | 标准 |
|------|------|
| 白 | 有扩项意识，有客户需求挖掘或增购经历 |

## 四、单元三板斧黑白灰（仅A7-M3）

### 画施工图

| 判定 | 标准 |
|------|------|
| 白 | 能制定完整作战计划，业绩目标拆解合理；主要项目风险有应对预案，执行基本顺畅，偶有微调不影响整体结果 |

### 选好骨干

| 判定 | 标准 |
|------|------|
| 黑 | 嫉贤妒能，��怕下属业绩超过自己；团队投诉、内耗严重，无可用骨干或骨干均为庸才，团队形同虚设 |
| 白 | 能识别优秀人才，任用基本合理；骨干队伍稳定，能支撑业绩指标 |

### 提高人效

| 判定 | 标准 |
|------|------|
| 白 | 稳定完成业绩目标，人均产出良好；重视人才培养，能带出可独立作战的骨干 |

---

## 五、判定优先级

1. **黑清单 > 灰清单 > 白清单**
2. 任一维度命中黑清单 → 直接判定面试不通过（C级淘汰）
3. 命中灰清单的维度需在报告中标注，录用时需结合整体评估综合考量
