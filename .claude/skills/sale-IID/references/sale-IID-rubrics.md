# 销售岗位面试综合评估 - 评分标准

> 本文件包含 sale-IID 的全部评分标准，SKILL.md 通过引用本文件获取评分规则。

---

## 一、AI能力（合格/不合格）

> **AI能力不再打分，只输出合格/不合格结论**
> - 判定标准：现在在使用AI工具辅助工作，就算**合格**
> - 不能用研发的标准来衡量（不需要写代码、造轮子）
> - 面试未提及AI能力 → 默认"合格"，评价写"暂无沟通记录"
> - 面试有提及但无法判断 → 默认"合格"

| 评价 | 说明 |
|------|------|
| 合格 | 正在使用AI工具辅助工作（包括ChatGPT、Claude、AI写文案、AI做PPT等） |
| 暂无沟通记录 | 面试中未涉及AI相关话题 |

| 分档 | 评分标准 |
|------|----------|
| 96–100分 | 有极强内驱力与成就感，发自内心热爱，无需督促就能持续攻坚，抗压性与斗志极强 |
