## 二、底色 — 兴趣（满分100）

| 分值区间 | 评分标准 |
|---------|----------|
| 90–100 | 极度热爱技术（数据库方向），主动啃难题、追前沿，愿长期深耕，以高质量系统为成就感来源 |
| 80–89 | 热爱研发，有技术追求，主动学习、主动攻坚 |
| 70–79 | 不排斥研发，能完成任务，愿意学习 |
| 60–69 | 兴趣一般，被动完成工作，不愿深度思考 |
| 0 | 厌恶技术/无有效信息 |

**简历可识别信号**：开源贡献、技术博客/社区活跃度、个人技术项目、自驱学习记录

**评分铁律**：简历中无法体现主动学习、技术热情等信号时，不得给予70分以上。

## 三、底色 — 狼性（满分100 = 主动侵略性40 + 目标刚性30 + 结果闭环30）

### 3.1 主动侵略性（满分40）

| 分值 | 标准 | 简历可识别信号 |
|-----|------|--------------|
| 40 | 无指令、无资源也能主动破局创造结果 | 简历明确描述：从0到1主导创建项目/系统、无资源条件下自驱突破 |
| 35 | 主动抢机会、抢目标、抢进展 | 简历明确描述：主动承担超出职责的项目/任务、竞标并主导关键方案 |
| 30 | 积极推进，不等不靠 | 简历明确描述：主动推动跨团队协作、自发优化流程/系统 |
| 25 | 安排才动，能执行 | 仅能从工作经历推断被动执行职责，无主动性描述 |
| 0 | 无有效信息 | 简历中无任何主动性相关描述 → **不打分** |

### 3.2 目标刚性（满分30）

| 分值 | 标准 | 简历可识别信号 |
|-----|------|--------------|
| 30 | 目标必达，死磕到底零借口 | 简历明确描述：攻坚记录、攻克关键技术难题、目标达成率100% |
| 27 | 重压下必完成，不放弃 | 简历明确描述：高压/紧迫工期下完成交付、应急响应成功记录 |
| 24 | 稳定达标 | 简历明确描述：按时交付记录、绩效达标 |
| 21 | 勉强完成 | 无明确达成记录 |
| 0 | 无有效信息 | 简历中无明确目标达成相关描述 → **不打分** |

### 3.3 结果闭环（满分30）

| 分值 | 标准 | 简历可识别信号 |
|-----|------|--------------|
| 30 | 凡事闭环，事事有最终结果 | 简历明确描述：项目完整交付且成果可量化、系统上线运行并有后续数据 |
| 27 | 主动反馈，有头有尾 | 简历明确描述：主动汇报进展、项目收尾有记录 |
| 24 | 能闭环，不甩锅 | 简历描述项目有始有终，有交付记录 |
| 21 | 需多次催促才收尾 | 无明确闭环信号 |
| 0 | 无有效信息 | 简历中无明确闭环相关描述 → **不做分** |

**狼性小计** = 主动侵略性 + 目标刚性 + 结果闭环（满分100）

## 四、底色 — 智商（满分100 = 毕业院校35 + 数学成绩45 + 简化能力20）

### 4.1 毕业院校（满分35）

| 分值 | 标准 | 验证方式 |
|-----|------|---------|
| 35 | 清华大学 / 北京大学 | 简历明确标注 |
| 31 | 华东五校（复旦、交大、同济、南大、浙大） | 简历明确标注 |
| 28 | 985院校 | 简历明确标注 |
| 24 | 211院校 | 简历明确标注 |
| ≤21 | 普通本科及以下 | 简历明确标注 |
| 0 | 无院校信息 | 简历未标注毕业院校 → **不打分** |

> ⚠️ **院校层次识别规范（强制）**：只有明确列入211工程的高校才可识别为211。常见易误判院校：
> 
> **易误判为211（实际不是211）**：
> - 中北大学、燕山大学、沈阳航空航天大学、哈尔滨理工大学、西安理工大学、昆明理工大学、杭州电子科技大学、成都信息工程大学、北方工业大学、沈阳工业大学
> 
> **易误判为非211（实际是211）**：
> - 大连海事大学 — **是211**
> 
> **易误判为普通211（实际是985）**：
> - 东南大学 — **是985**
> 
> - 遇不确定时，优先查询确认，不确定按低等级处理

### 4.2 数学成绩（满分45）

| 分值 | 标准 | 验证方式 |
|-----|------|---------|
| 45 | 数理竞赛国家奖 / 省一等奖 | 简历明确标注 |
| 40 | 高考数学 ≥ 135分 | 简历明确标注 |
| 35 | 高考数学 120–134分 | 简历明确标注 |
| 30 | 高考数学 105–119分 | 简历明确标注 |
| ≤25 | 高考数学 < 105分 | 简历明确标注 |
| 0 | 无数学成绩信息 | 简历未标注数学成绩 → **不打分** |

> **绝大多数简历不会标注高考数学成绩，此子项通常为0分。**

### 4.3 简化能力（满分20）

| 分值 | 标准 | 简历可识别信号 |
|-----|------|--------------|
| 20 | 一眼穿透本质，复杂→极简 | 简历表达极度精炼、技术方案描述简洁有力、复杂问题用简单方式解决 |
| 18 | 结构化梳理，剔除冗余 | 简历结构清晰、技术描述有条理、无冗余信息 |
| 16 | 能讲清楚，但不够精炼 | 简历基本清晰但略显冗长 |
| 14 | 重点模糊，表达偏散 | 简历逻辑不清、描述散乱 |
| 0 | 无有效信息 / 越讲越复杂 | 简历无结构或极为混乱 |

**智商小计** = 毕业院校 + 数学成绩 + 简化能力（满分100）

## 五、AI能力（满分100）

| 分值区间 | 评分标准 | 简历可识别信号 |
|---------|----------|--------------|
| 90–100 | 主动拥抱AI，精通各类工具，显著提升效率，带动团队 | 简历明确描述：AI工具深度应用、AI赋能全流程、AI创新实践、带动团队AI化转型 |
| 80–89 | 认可AI价值，熟练使用核心工具辅助，效率提升明显 | 简历明确描述：AI工具使用经验、AI辅助开发/测试记录、关注AI新应用 |
| 70–79 | 被动使用AI，掌握基础功能，效率提升不明显 | 简历提及AI工具但描述浅显 |
| 60–69 | 尝试使用AI但不得法，效果差 | 简历偶有提及AI但不系统 |
| 0 | 拒绝使用AI / 无有效信息 | 简历中无AI相关描述 → **不打分** |

## 六、三板斧能力（1~5级 → 分值映射）

| 级别 | 对应分值 |
|-----|---------|
| 1 | 60 |
| 2 | 65 |
| 3 | 75 |
| 4 | 85 |
| 5 | 95 |

### 评分原则

三板斧能力通常需要面试综合考察，**简历仅能提供有限信号**。
评估时仅根据简历中可识别的明确信息进行评级：

- **打深井**：技术领域深耕年限（明确数字）、项目深度描述、核心模块开发经验、技术专精度
- **简化**：技术方案简洁性描述、问题拆解能力体现、简历整体逻辑清晰度
- **质量好**：代码质量意识提及、测试覆盖率描述、文档完整性、项目稳定性/可用性描述

**如果简历中无充分明确信息支持评级，则该维度评为1级（60分）或标注"无有效信息"。**

## 七、基准线与评级规则

### 基准线（各层级通用，任一不满足则降级为合议）

| 基准项 | 最低要求 |
|--------|----------|
| 兴趣 | ≥ 80 |
| 狼性 | ≥ 80 |
| 智商 | ≥ 80 |
| AI能力 | ≥ 80 |

### 各薪酬级别最低总分

| 级别段 | A1-A3 | A4-A6 | P1-P3 | P4-P6 | A7-A9 | M1-M3 |
|--------|--------|--------|--------|--------|--------|--------|
| 最低总分 | ≥70 | ≥74 | ≥79 | ≥84 | ≥79 | ≥82 |

### 评级规则

| 条件 | 评级 |
|------|------|
| 任一维度命中黑清单 | **淘汰**（一票否决，无论评分高低） |
| 加权总分 ≥ 对应级别最低线 且 所有基准项 ≥ 80 | **录用** |
| A1-A3级总分60~70 | **合议**（需进一步面试评估） |
| 其他未达线但未淘汰 | **合议** |
| 加权总分 < 60 | **淘汰** |

## 八、快速零分预判（加速机制）

简历评分中，部分维度在绝大多数简历里都**不可能有对应信息**。为了加速分析，
在读简历时执行**单次快速扫描**，对以下维度做即时零分判定——只要扫描不到明确信号，直接记0分，跳过该维度的详细评估：

| 维度 | 预判规则 | 扫描信号（有则评、无则0） |
|------|---------|----------------------|
| 智商-数学成绩 | **默认0分** | 简历出现"高考数学"、"数理竞赛"、"数学成绩"等明确数字 |
| 狼性-主动侵略性 | **默认0分** | 出现"从0到1"、"主导创建"、"自驱突破"、"主动承担超出职责"等明确主动性描述 |
| 狼性-目标刚性 | **默认0分** | 出现"攻坚"、"攻克难题"、"目标达成率100%"、"高压交付"等明确目标达成描述 |
| 狼性-结果闭环 | **默认0分** | 出现"项目完整交付"、"系统上线运行"、"成果可量化"、"闭环"等明确闭环描述 |
| 兴趣 | **默认0分**（除非有明确信号） | 出现开源项目/GitHub链接、技术博客、个人技术项目、自驱学习记录 |
| AI能力 | **默认0分**（除非有明确信号） | 出现AI工具名称（ChatGPT/Claude/Copilot等）、AI赋能/AI辅助相关描述 |

**需要正常评估的维度**（通常简历中都能找到信息）：
- **智商-毕业院校**：简历几乎必有院校信息，直接按层次评分
- **智商-简化能力**：从简历整体表达质量直接评估
- **三板斧-打深井**：从项目经历的技术深度评估
- **三板斧-简化**：从技术方案描述的简洁性评估
- **三板斧-质量好**：从测试/文档/稳定性相关描述评估

**执行方式**：读取简历时一次性完成扫描，命中零分预判的维度直接在评分表中填0，不做二次搜索或重新读取。
