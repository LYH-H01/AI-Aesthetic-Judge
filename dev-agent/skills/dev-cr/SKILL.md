# devCR — 研发岗位简历筛选与分析

## 功能定位

读取候选人简历，依据黑白灰清单规则和评分标准，对**全部5个维度**进行逐维度、全覆盖的黑白灰规则判定与分析，输出简历筛选结论及面试官参考信息。

> **重要提示**：本 skill 执行时需要读取：
> - `references/dev-cr-blackwhite.md` 获取完整的黑白灰规则
> - `references/dev-cr-rubrics.md` 获取完整的评分标准

## 输入要求

- **简历文件**：PDF、Word、直接粘贴文本
- **岗位类型**（可选）：X1/X2/X3/特殊人才/A7-A9/M1-M3，默认X2
- **JD命令**（可选）：`/jd-{岗位标识}` 格式，触发岗位匹配度分析

## 执行流程

### 第一步：读取简历（单次读取 + 快速预判）

- 读取简历内容
- 按"快速零分预判"表扫描，将无信号的维度即时标0

### 第二步：黑白灰分析

> **黑白灰规则详见** `references/dev-cr-blackwhite.md`

对5个维度逐一评估：
- 目标学校、目标公司、岗位、在职情况、年龄

评估结果以表格输出：

```
| 评估维度 | 判定结果 | 简要说明 |
|------------|----------|----------|
| 目标学校 | [黑/灰/白] | [规则引用] |
| 目标公司 | [黑/灰/白] | [规则引用] |
| 岗位 | [黑/灰/白] | [规则引用] |
| 在职情况 | [黑/灰/白] | [规则引用] |
| 年龄 | [黑/灰/白] | [规则引用] |
```

### 第三步：简历评分

- 跳过预判为0的维度
- 对有明确信息的维度依据评分标准打分
- 计算狼性小计、智商小计、三板斧各维度分值
- 按权重计算加权总分

### 第四步：岗位匹配（仅当有JD命令时）

解析 `/jd-{岗位标识}` 命令，检索对应JD文件，进行匹配度分析。

### 第五步：输出报告

```
**[评分: {加权总分} | 评级: {录用/合议/淘汰} | 黑白灰: {黑/灰/白}]**

### 〇、简历评分

[黑白灰判定表]

### 二、结论：是否通过
[通过/不通过/边缘通过]

### 三、面试提点
```

## 院校层次识别规范（重要）

识别毕业院校层次时务必谨慎，常见易混淆院校：

| 院校 | 正确层次 | 易误判为 |
|------|---------|---------|
| 东南大学 | **985** | 普通211（实际是985） |
| 大连海事大学 | **211** | 非211（实际是211） |
| 中北大学 | **非985 / 非211** | 211（实际不是211） |

**判断原则**：
1. 不确定的院校，优先查询确认
2. 查不到的院校按低等级处理
3. 不得仅凭校名中的"大学"字样或省份名校推断层次

## 评分铁律（不可违反）

1. **只允许根据简历中明确出现、可被直接验证的信息进行打分**
2. **信息缺失 = 0分**：简历上无法识别相应信息的子项，直接记0分
3. **需要明确数据/文字支撑的项目**，简历中没有对应信息同样记0分
4. **打分必须100%基于简历原文**，不得加入任何简历外的个人判断
5. **狼性、主动侵略性、目标刚性、结果闭环、简化能力**等性格/能力维度，如果简历中没有相关描述，该子项必须为0分
