# 售前POC岗位评分标准

> **注意**：此文件为售前POC岗位专用评分标准。交付岗位请使用 `delScoringRubric.md`。
>
> **核心原则（铁律）**：
> 1. 只允许根据简历中**明确出现、可被直接验证**的信息进行打分
> 2. 简历中无对应维度的直接信息 → 该维度**必须为0分**或标注"无有效信息，不打分"
> 3. **禁止**任何形式的主观推断、脑补、臆测打分
> 4. 需要明确数据/文字支撑的项目（如毕业院校、数学成绩），简历中无对应信息同样记0分
> 5. 打分必须100%基于简历原文，不得加入任何简历外的个人判断

## 二、岗位三板斧（百分制）

售前POC岗位三板斧包含**快**和**赢单**2个维度。

### 2.1 快（按权重计算：态度20%+硬能力50%+软能力30%）

- **态度（20%权重）及格线60分**：将"快"作为工作习惯，主动抢跑、提前规划闭环
- **硬能力（50%权重）及格线60分**：独立完成POC用例，输出标准POC报告
- **软能力（30%权重）及格线60分**：AI辅助应用，流程优化

### 2.2 赢单
- **无固定及格线**（按同档排名评估）：
  - 80–100分：5级 人效+赢单率同档Top10%
  - 60–80分：4级 人效+赢单率同档Top30%
  - 40–60分：3级 人效+赢单率同档Top50%
  - <40分：2级 人效+赢单率同档Bottom50%

## 五、加权总分计算（售前POC非单元岗位）

| 考核项 | 权重 |
|-------|------|
| 底色-狼性 | 22.5% |
| 底色-智商 | 27.5% |
| 岗位三板斧-快 | 35% |
| 岗位三板斧-赢单 | 15% |

**加权总分** = 狼性小计×22.5% + 智商小计×27.5% + 快得分×35% + 赢单得分×15%

## 六、评级规则

| 条件 | 评级 |
|------|------|
| 任一维度命中黑清单 | **淘汰** |
| 基准项全部≥及格线 且 加权总分≥70 | **录用** |
| 基准项有任一项<及格线 或 加权总分60-70 | **合议** |
| 加权总分<60 | **淘汰** |
