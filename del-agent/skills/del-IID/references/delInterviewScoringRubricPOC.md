# 售前POC岗位面试评分标准

> 本文件用于指导AI进行售前POC岗位面试评分
> **注意**：与交付岗位共用黑白灰清单和录用规则，仅评分标准有差异

---

## 一、底色评分标准

### AI能力（及格线≥80）

| 分值 | 标准 |
|------|------|
| 90-100 | 主动拥抱AI，精通各类AI工具，显著提升故障处理效率、人效远超团队平均，持续学习并带动团队 |
| 80-89 | 认可AI价值，熟练使用主流AI工具，主动关注AI新应用并乐于分享 |
| 60-79 | 被动使用AI，掌握基础功能，效率提升不明显，主动性弱 |
| 40-59 | 尝试使用但不得法，效果差，学习意愿低，未带来实际效益 |
| <40 | 拒绝AI，固守旧法，效率低下，抵制学习，躺平摆烂 |

### 兴趣（及格线≥80）

| 分值 | 标准 |
|------|------|
| 90-100 | 热爱服务与交付，以客户成功为成就，主动解决问题、扛事、优化 |
| 80-89 | 认可服务价值，责任心强，主动跟进，耐心抗压 |
| 60-79 | 不排斥服务，能按流程完成，耐心尚可 |
| 40-59 | 兴趣一般，被动响应，易烦躁 |
| <40 | 讨厌服务、怕客户、怕麻烦，推诿敷衍 |

### 情商（及格线≥70）

| 分值 | 标准 |
|------|------|
| 90-100 | 极度耐心稳定，先安抚再解决，扛压扛委屈，能化解冲突、建立信任 |
| 80-89 | 情绪稳定，会安抚客户，冲突理性处理 |
| 70-79 | 基本耐心，职业规范内沟通正常 |
| 40-59 | 耐心不足，易烦躁，态度易受影响 |
| <40 | 情绪易爆，怼客户、甩脸色，破坏口碑 |

### 狼性（及格线≥80）

| 分值 | 标准 |
|------|------|
| 90-100 | 问题不解决不离场，紧急故障主动扛，再苦再累也要交付成功 |
| 80-89 | 以客户成功为底线，敢担责、不甩锅，问题闭环到底 |
| 60-79 | 能按要求完成交付，有基本责任心 |
| 40-59 | 怕麻烦怕加班，被动应付，主动性弱 |
| <40 | 怕担责、敷衍推诿、情绪优先 |

**狼性补充评估（30分制）：**
- **目标必达**：30分=零借口死磕到底；27分=重压下必完成；24分=稳定达标；21分=勉强达标；<21分=不达标
- **凡事闭环**：30分=事事有最终结果；27分=主动反馈有头有尾；24分=能闭环不甩锅；21分=被动闭环易甩锅；<21分=常甩锅不闭环

## 三、岗位三板斧评分标准（售前POC）

### 快-态度（20%权重，及格线≥60）

| 分值 | 标准 |
|------|------|
| 80-100 | 将"快"作为工作习惯，主动抢跑、提前规划闭环；预判风险、提前制定方案；主动优化流程、提效降本；响应极快、保质保量；成为团队标杆 |
| 60-80 | 具备紧迫感、愿意提速；按时闭环、件件有着落；协作顺畅、主动跟进、及时同步；不拖延、不甩锅 |
| <60 | 被动应付、推诿责任、负面情绪影响团队 |

### 快-硬能力（50%权重，及格线≥60）

| 分值 | 标准 |
|------|------|
| 95-100 | 1.独立完成数据库单机、极简集群部署，适配常规信创软硬件；2.熟练运行标准POC用例，处理配置、端口、权限、工具运行等基础故障；3.整理测试数据、输出标准POC报告，独立交付中小型标准POC；4.识别基础报错、看懂简单日志、规范提报问题 |
| 80-90 | 1.主导常规POC全流程（需求拆解→环境规划→用例设计→交付），适配多芯片/OS/中间件复杂信创组合；2.编写基础数据/测试脚本、定制简单用例，独立完成性能/稳定性压测并输出基础调优建议；3.独立解决现场80%以上常见问题，无需后台支持，现场解答基础技术问题；4.沉淀POC用例/脚本/问题库，输出可直接赢单的POC材料 |
| 70-80 | 1.负责大型/集团级/战略级信创POC整体技术方案，完成数据库深度性能、参数、架构调优；2.具备团队二线专家或区域1/2号位能力，攻坚ISV适配、兼容性、数据迁移疑难问题，主导竞品对标、设计对抗用例；3.对接客户技术高层，提供架构级支撑，输出专业性能报告支撑决策；4.制定部门POC规范、流程、质量标准，支撑产品优化需求输出 |
| 60-70 | 1.制定数据库POC全行业测试标准与方法论，主导核心信创生态适配认证（芯片/OS/中间件/重大行业应用）；2.攻坚卡脖子技术、跨产品/架构系统性难题，支撑产品竞争力提升；3.搭建公司POC技术/人才/工具体系，主导前沿技术预研与POC落地；4.对接信创生态联盟，参与行业共建/专项课题，提供技术决策与风险评估，输出行业级信创方案 |
| <60 | 1.引领数据库售前技术方向，制定技术路线，参与国家/行业信创标准编写与评审；2.参与公司数据库技术战略规划，决策重大技术方向、产品架构、生态布局；3.解决行业共性难题，统筹全国重大POC技术支撑，提升行业话语权；4.对接国家部委、行业专家、核心客户高层，制定技术壁垒与竞争力规划；5.输出技术白皮书、行业方案、实战专著 |

### 快-软能力（30%权重，及格线≥60）

| 分值 | 标准 |
|------|------|
| 80-100 | AI体系应用：搭建团队AI工具链，AI赋能POC全流程；主导POC团队日常运营，制定流程/考核/文档标准，协调跨部门资源；负责中大型POC全流程管理，把控风险、质量与合规 |
| 60-80 | AI深化应用：测试脚本辅助、问题排查匹配、用例梳理优化；带教新人流程/工具/红线，统筹小型团队任务；负责小型POC进度、质量管控，输出复盘与过程文档 |
| <60 | AI基础应用：数据整理、标准报告、文档初稿等基础提效；遵守流程、细则、红黄线，按时闭环；独立完成基础文档，同步进度、上报问题、配合协作 |

**快小计** = 态度×20% + 硬能力×50% + 软能力×30%

## 五、评分铁律

1. **所有评分必须有明确依据**——面试文本原话，拒绝无依据打分
2. **面试文本中未涉及的维度**，按基准线给分并标注"建议后续核实"
3. **基准线**：AI能力/兴趣/狼性/智商取80分，情商取70分
4. **三板斧1~5级映射**：1级=60, 2级=65, 3级=75, 4级=85, 5级=95
