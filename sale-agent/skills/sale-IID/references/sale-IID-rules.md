# 销售岗位面试综合评估 - 录用规则

> 本文件包含 sale-IID 的全部录用规则，SKILL.md 通过引用本文件获取录用判定规则。

---

## 一、强制淘汰铁律

> **以下任一条件触发，直接判定 C/D（淘汰），无需计算总分：**

| 淘汰条件 | 说明 |
|----------|------|
| 加权总分 < 总分线 | X2/X3/A7-A9/M1-M3按各自总分线执行 |
| 兴趣 < 80 | 底色核心子项 |
| 狼性均分 < 80 | 底色核心子项 |
| 情商均分 < 80 | 底色核心子项 |
| 简历黑白灰 = 黑 | 直接淘汰 |

> **注意：先检查单项门槛，再计算总分，最后匹配等级。任一单项不达标即淘汰。**

> **关于AI能力：**
> - 判定标准：现在在使用AI工具辅助工作，就算**合格**
> - 不能用研发的标准来衡量（不需要写代码、造轮子）
> - 面试未提及AI能力 → 默认"合格"，评价写"暂无沟通记录"
> - 评价结果输出：合格/不合格

## 二、X1录用规则

**单项门槛（任一不达标即淘汰）：**
- 底色（兴趣+狼性+情商）：均分≥80
- 岗位三板斧（快）：≥60
- 简历黑白灰 ≠ 黑

> **关于AI能力：不作为考核项，默认合格**

- 岗位三板斧（快+专业知识+输出质量）：≥60

> **关于AI能力：不作为考核项，默认合格**

## 八、面试黑白灰判定

> **面试中出现以下情况，直接判定为灰/黑：**

| 判定 | 条件 |
|------|------|
| 黑 | 简历造假/学历伪造/经历虚构 |
| 黑 | 严重逻辑不通，回答驴唇不对马嘴 |
| 灰 | 表达逻辑混乱，需要多次追问才能理解 |
| 灰 | 对过往业绩无法自圆其说，含糊其辞 |

---

## 九、评分流程

1. **解析简历评分**：提取 cr-new 输出中的现有分数
2. **解析面试内容**：按评估维度归类
3. **判定面试黑白灰**：先查黑名单，有则直接淘汰
4. **面试补充评分**：对"需面试补充"的维度基于面试表现打分
5. **合并评分**：取简历分与面试分的较高值
6. **检查选好骨干**：仅A7-A9（≥80）/M1-M3（≥90），按岗位类型门槛检查
7. **检查加权总分**：按岗位类型总分线检查（X2≥70/X3≥75/A7-A9≥77/M1-M3≥80）
8. **（AI能力不作为考核项，默认合格）**

---

## 十、评分铁律

1. **所有评分必须有简历/面试原文依据**，严禁凭空打分
2. **面试未涉及维度** → 标注"未涉及，建议后续核实"，底色默认70，岗位三板斧默认60
3. **黑白灰=黑** → 直接淘汰，无需评分
4. **先检查单项��槛，再计算总分，最后匹配等级**
5. **任一单项不达标即淘汰，不因总分高而豁免**
6. **对比与综合评价部分必须使用美观Markdown格式输出**
7. **淘汰结论必须明确标注哪一项未达标**
8. **综合评价中关于AI能力**：不要分析"没使用过"等缺点，有优点可以夸
   - 合格 → 写"AI工具使用能力合格"即可，无需展开
   - 不合格 → 写"暂无AI工具使用记录"即可
