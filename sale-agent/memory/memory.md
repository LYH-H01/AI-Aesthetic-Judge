### 十四、sale-IID底色计算公式（V4对齐版）

> ⚠️ **AI能力处理规则（2026-05-14更新）**：
> - 权重占比：**0**，不参与加权总分计算
> - 不体现具体分数，只输出**合格/不合格**
> - 面试未提及：默认"合格"，评价写"暂无沟通记录"
> - 面试有提及：直接输出合格/不合格，不打分
> - 不作为否定项，所有候选人默认通过

```
底色 = 兴趣×0.30 + 狼性均分×0.30 + 情商均分×0.30
狼性均分 = (主动侵略性 + 目标刚性 + 结果闭环) ÷ 3
情商均分 = (信任构建能力 + 人性洞察能力 + 长期价值绑定) ÷ 3
```

**V4权重变更（2026-05-11同步）**：
- AI能力：8%（加权项）→ 否定项（不参与加权，单独pass/fail判定≥80）
- 兴趣：15% → 20%
- 情商各项：各4% → 各5%
- 底色公式：情商均分×0.24 → 情商均分×0.30
- 底色权重合计：兴趣20%+狼性15%+情商15% = 50%（占总加权100%的一半）
